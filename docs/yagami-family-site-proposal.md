## 設計提案

### サイト構造（アスリートサイトのベストプラクティス適用）

```
矢上家のライフセービングな日常
├── トップ (Hero)          ← フルスクリーン写真 + キャッチコピー
├── ABOUT                   ← 矢上家とは / 家族紹介
├── ACTIVITY                ← 活動記録（ブログ・ニュース）
├── GALLERY                 ← 写真・動画ギャラリー
├── SUPPORT                 ← サポーター募集 + 寄付
├── SCHEDULE                ← 今後の活動予定
└── CONTACT / SNS           ← お問い合わせ・SNSリンク
```

### ページ詳細

#### 1. トップページ（Hero）
- **フルスクリーンヒーロー画像**（海・ライフセービングの臨場感）
- キャッチコピー例：
  - 「海を、命を、家族で守る。」
  - 「砂浜の向こう側に、僕たちの日常がある。」
- スクロールで次のセクションへ誘導（↓アニメーション）
- 参考：レブロン・ジェームズの没入型ヒーロー

#### 2. ABOUT（矢上家とは）
- **家族全員のプロフィールカード**（写真 + 名前 + 役割 + 一言）
- ライフセービングとの出会い・歩みをタイムライン形式で
- 「なぜライフセービングなのか」ストーリー
- 参考：本田圭佑の多面的アイデンティティ表現

#### 3. ACTIVITY（活動記録）
- **ブログ形式のニュースフィード**（日時 + サムネイル + タイトル）
- カテゴリー分け：大会 / トレーニング / 地域活動 / メディア出演
- 参考：久保建英のNEWSセクション

#### 4. GALLERY（ギャラリー）
- **写真ギャラリー**（ライトボックス表示）
- アルバム分類：大会 / 練習 / 日常 / イベント
- 動画埋め込み（YouTube連携）
- 参考：Instagram風のグリッドレイアウト

#### 5. SUPPORT（サポーター募集）⭐ 最重要
- **3つのサポート方法**：

**① ワンタイム寄付（単発応援）**
- Stripe Payment Links（既にアカウントあり！）
- 金額選択：1,000円 / 3,000円 / 5,000円 / 自由入力
- 「応援メッセージ」付き

**② 月額サポーター（継続支援）**
- Stripe Subscriptions で月額制
- ティア例：
  - 🏖️ **ビーチサポーター**（月500円）— お礼メール + 名前掲載
  - 🌊 **ウェーブサポーター**（月1,000円）— 限定レポート + 名前掲載
  - 🏅 **ガーディアン**（月3,000円）— 限定コンテンツ + グッズ + 名前掲載
- 参考：SLS Foundation「Guardians of the Surf」モデル

**③ スポンサー（企業・団体向け）**
- 問い合わせフォームで個別対応
- 参考：Find-FCの費用透明開示モデル

**サポーター一覧**
- 寄付者・サポーターの名前を掲載（芳名録）
- 参考：JLAの寄付者芳名録

**寄付の使い道**
- 透明な費用開示：遠征費、機材費、トレーニング費etc.
- 参考：Find-FCの費用ブレークダウン

#### 6. SCHEDULE
- 大会・イベントカレンダー
- 過去の戦績・実績一覧

## 日本の寄付・サポータープラットフォーム比較

| プラットフォーム | 手数料 | 特徴 |
|-----------------|--------|------|
| **Stripe**（推奨）| 3.6% | 既にアカウントあり！Payment Links + Subscriptions |
| Syncable | 5% | NPO向け、ピアツーピア募金 |
| FANCLOVE | 8%〜 | ファンクラブ運営、月額課金 |
| codoc | 15% | コンテンツ課金 + 投げ銭 |
| OFUSE | 可変 | 投げ銭特化 |

**推奨：Stripe**（E-Lifeで既にアカウント設定済み、手数料最安、自由度最高）
