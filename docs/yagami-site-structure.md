# 矢上家のライフセービングな日常 — サイト構成案

## 基本方針
- **構成**: ストーリー型（LP風トップ + サブページ）
- **メインキャスト**: 長女・次女・長男（3人のライフセーバー）
- **サポートキャスト**: 父（矢上真吾）・母
- **言語**: 日本語 + 英語（見出し英語 + 本文日本語ベース、将来的に英語版追加）
- **サポーター**: 月額制 + ワンタイム寄付の両方
- **技術**: Sanity + Next.js + Vercel + Stripe

---

## グローバルナビゲーション

```
[ロゴ: 矢上家]  HOME | ABOUT | ACTIVITY | GALLERY | SUPPORT  [EN/JP] [🍔]
```

- PC: 上部固定ヘッダー（スクロールで半透明背景）
- スマホ: ハンバーガーメニュー
- 言語切替トグル（EN/JP）

## Sanity コンテンツスキーマ

### familyMember（家族メンバー）
| フィールド | タイプ | 説明 |
|-----------|--------|------|
| name | string | 名前 |
| nameEn | string | 英語名 |
| slug | slug | URL用スラッグ |
| role | string | 役割（アスリート/サポート） |
| photo | image | プロフィール写真 |
| bio | text | 自己紹介 |
| bioEn | text | 英語自己紹介 |
| events | array[string] | 出場種目 |
| achievements | array | 戦績リスト |
| quote | string | 一言コメント |
| order | number | 表示順 |
| isMainCast | boolean | メインキャストか |

### activity（活動記録）
| フィールド | タイプ | 説明 |
|-----------|--------|------|
| title | string | タイトル |
| titleEn | string | 英語タイトル |
| slug | slug | URL用スラッグ |
| publishedAt | datetime | 日付 |
| category | string | カテゴリ（大会/練習/地域/メディア） |
| thumbnail | image | サムネイル |
| body | portableText | 本文（リッチテキスト） |
| bodyEn | portableText | 英語本文 |
| gallery | array[image] | 記事内写真 |
| members | array[ref] | 関連メンバー |

### galleryItem（ギャラリー）
| フィールド | タイプ | 説明 |
|-----------|--------|------|
| image | image | 写真 |
| caption | string | キャプション |
| captionEn | string | 英語キャプション |
| category | string | カテゴリ |
| takenAt | date | 撮影日 |
| members | array[ref] | 写っているメンバー |

### event（イベント・大会）
| フィールド | タイプ | 説明 |
|-----------|--------|------|
| title | string | 大会名 |
| titleEn | string | 英語名 |
| date | date | 日付 |
| location | string | 場所 |
| participants | array[ref] | 出場メンバー |
| results | array | 結果（順位など） |
| isUpcoming | boolean | 今後の予定か |

### supporter（サポーター）
| フィールド | タイプ | 説明 |
|-----------|--------|------|
| name | string | 表示名 |
| tier | string | ティア（guardian/wave/beach/donation） |
| since | date | サポート開始日 |
| isPublic | boolean | 名前公開するか |

### siteSettings（サイト設定）
| フィールド | タイプ | 説明 |
|-----------|--------|------|
| siteTitle | string | サイト名 |
| description | text | サイト説明 |
| heroImage | image | ヒーロー画像 |
| heroText | string | ヒーローキャッチコピー |
| socialLinks | object | SNSリンク集 |

## デザインシステム

### カラーパレット（海テーマ）
```
Primary（海の青系）:
  --ocean-deep:    #0A1628   ← ダークセクション背景
  --ocean-dark:    #0C2D48   ← ヘッダー・フッター
  --ocean:         #1A5276   ← メインカラー
  --ocean-mid:     #2E86AB   ← ボタン・リンク
  --ocean-light:   #87CEEB   ← アクセント

Warm（砂浜・夕焼け系）:
  --sand:          #F5E6C8   ← ライトセクション背景
  --sand-light:    #FBF5EC   ← ベース背景
  --sunset:        #E8724A   ← CTA・アクセント
  --sunset-light:  #F4A261   ← ホバー

Neutral:
  --white:         #FFFFFF
  --text-dark:     #1A1A2E
  --text-mid:      #4A4A5A
  --text-light:    #8B8B9B

Special:
  --lifesaving-red:  #E63946  ← ライフセービングの赤
  --guard-yellow:    #FFD700  ← ライフガードの黄色
```

### タイポグラフィ
- **見出し（日本語）**: Noto Serif JP — 品格
- **本文（日本語）**: Noto Sans JP — 読みやすさ
- **英字見出し**: Outfit or Montserrat — モダン・スポーツ感
- **英字アクセント**: Cormorant Garamond — 上品

### アニメーション
- スクロール連動のフェードイン（Framer Motion）
- ヒーロー画像のパララックス
- ページ遷移アニメーション
- ホバーエフェクト（カード拡大、色変化）

## モバイル対応

### ブレークポイント
- **スマホ**: < 640px（1カラム）
- **タブレット**: 640px - 1024px（2カラム）
- **PC**: > 1024px（フル表示）

### スマホ特有の対応
- ハンバーガーメニュー（フルスクリーンオーバーレイ）
- ギャラリーは横スワイプ
- サポーターティアはカードスワイプ
- ヒーロー画像のクロップ調整
